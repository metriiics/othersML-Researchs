# OvR (OneVsRestClassification)

OvR (One-vs-Rest, или "один против всех") — это стратегия многоклассовой классификации. Основная идея: Для $K$ классов обучается $K$ бинарных классификаторов (например, персептронов). Каждый i-й классификатор отличает i-й класс от всех остальных.

## Реализация 

`Perceptron` - содержит базовую ООП реализацию персептрона для бинарной классификации.

`ovr` - класс OneVsRestClassifier содержит методы `fit` и `predict`. 
Класс принимает объект бинарного классификатора. Делит таргет на множество n классов. И обучает i-ю модель для i класса. Предикт предполагает отметку класса и оценку. `(array([0]), array([[1., 0., 0.]]))`, метка класса - 0, вектор, ответа, 1-ая модель предсказала свой класс.
